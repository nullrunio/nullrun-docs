# Documentation Audit Report — 2026-08-25

Cross-checked all 44 documentation files in `docs/` against the real
Python SDK source (`nullrun-sdk-python/src/`) and the Rust backend
source (`NULLRUN/backend/src/`).

## Scope

- **Verified:** 44 markdown files (`getting-started/`, `concepts/`,
  `how-to/`, `reference/`, `compliance/`, `index.md`, `troubleshooting.md`).
- **Sources:** `nullrun-sdk-python/src/nullrun/*.py` and
  `NULLRUN/backend/src/**`.
- **Date:** 2026-08-25.
- **Method:** automated discrepancy search + manual cross-check.

## HIGH severity discrepancies

### SDK surface

1. **`docs/reference/sdk-api.md:42` — `chain()` signature wrong**
   - Doc: `chain(name=None, *, chain_op="auto")`.
   - Real: `chain(chain_id: str, op: str = "start")`
     (`src/nullrun/context.py:859-863`).
   - Impact: every chain example in docs raises `TypeError`.

2. **`docs/reference/sdk-api.md:29,36` — `init_or_die()` signature wrong**
   - Doc: `init_or_die(api_key=None, api_url=None, debug=False)`.
   - Real: `init_or_die(*, api_key=None, api_url=None, debug=False,
     exit_code=1)` (`src/nullrun/_handle.py:143-144`).
   - Impact: positional invocation broken; `exit_code` undocumented.

3. **`docs/reference/sdk-api.md:35` — `init()` capability probe mis-described**
   - Doc: "Probes `GET /api/v1/capabilities` to validate wire protocol."
   - Real: probe only logs warnings on version drift; does not validate
     the wire (`src/nullrun/__init__.py:357-381`).

4. **`docs/reference/sdk-api.md:47-49` — `track_llm` / `track_tool` signatures wrong**
   - Doc: explicit kwargs (`model`, `latency_ms`, `is_retry`, `metadata`).
   - Real: only `input_tokens`, `output_tokens` (track_llm) and
     `tool_name`, `duration_ms` (track_tool) are named; the rest are
     `**kwargs` (`src/nullrun/runtime.py:3612-3644`).

5. **`docs/concepts/error-handling.md:36-53` — listed error codes are wire codes, not SDK codes**
   - Doc: examples like `"BUDGET_HARD_BLOCKED"`, `"TOOL_BLOCKED"`,
     `"RATE_LIMIT_EXCEEDED"`.
   - Real: SDK `NullRunError.error_code` uses NR-* codes
     (`NR-B004`, `NR-T001`, `NR-R001` etc. — `src/nullrun/messages.py:59-94`).
   - Impact: `err.error_code == "BUDGET_HARD_BLOCKED"` in user code
     never matches.

6. **`docs/concepts/error-handling.md:36-41` — error_code "example" column wrong**
   - Same root cause as #5.

7. **`docs/concepts/error-handling.md:58-71` — `RateLimitError` field example**
   - Doc: `exc.error_code = "RATE_LIMIT_EXCEEDED"`.
   - Real: `exc.error_code = "NR-R001"`.

8. **`docs/getting-started/configuration.md:24-37` — server-side env vars documented as SDK config**
   - Doc lists `NULLRUN_HMAC_REQUIRED`, `NULLRUN_GEOBLOCK_DISABLED`,
     `NULLRUN_SANCTIONS_SCREENING_DISABLED` alongside SDK env vars.
   - Real: none of these are read by the SDK (grep confirms).

9. **`docs/getting-started/configuration.md:44-52` — feature flags listed as SDK env vars**
   - Doc: `NULLRUN_RESERVE_V3_ENABLED`, `NULLRUN_CONSUME_V3_ENABLED`,
     `NULLRUN_USE_OUTBOX_FOR_TRACK`, `NULLRUN_RATE_LIMIT_ALGORITHM`,
     `NULLRUN_USE_PLAN_FOR_COST_EVENTS`.
   - Real: all server-side only.

10. **`docs/reference/errors.md:155-168` — HTTP status mapping wrong for budget**
    - Doc: `BUDGET_HARD_BLOCKED → 429`.
    - Real: → `402 Payment Required`.

13. **`docs/how-to/streaming.md:44,56` — `chain_op="start"` kwarg wrong**
    - Real kwarg is `op="start"` (same as #1).

14. **`docs/how-to/multi-agent-orchestration.md:48-74` — nested `workflow()` budget semantics**
    - Doc: "budget cap enforced across the whole tree".
    - Real: each `workflow()` has its own `workflow_id`; nesting does
      not inherit budget.

### Backend surface

1. **`docs/reference/http-api.md:102` — `/api/v1/policies/toggle` documented as live (security regression)**
   - Doc: `/api/v1/policies/toggle` listed in endpoint table.
   - Real: removed path. Live route is
     `/api/v1/orgs/:org_id/policies/:policy_id/toggle`
     (`backend/src/proxy/http/routes.rs:497-500`).
   - Impact: doc documents a removed tenancy-bypass path.

2. **`docs/concepts/workflow.md`, `api-keys.md`, `human-approval.md` — fabricated `GateRequest` fields**
   - Doc claims: `cost_source`, `stream`, `idempotency_key`.
   - Real (`backend/src/proxy/http/gate/internal.rs:121-200`):
     `organization_id`, `execution_id`, `trace_id`, `tool`, `input`,
     `mode`, `check_type`, `model`, `estimated_tokens`, `operation_id`,
     `tools`, `chain_id`, `chain_op`, `approval_id`, `business_impact`,
     `action_digest`, `tool_digest`, `tool_params`, `parent_execution_id`.
   - Impact: SDK generators built from these docs produce incompatible
     payloads.

3. **`docs/concepts/error-handling.md:48` — `REDIS_UNAVAILABLE` not a wire code**
   - Real canonical wire code is `BUDGET_REDIS_UNAVAILABLE`
     (`backend/src/proxy/http/gate/error_codes.rs:351`).

4. **`docs/getting-started/configuration.md:16` — HMAC production default wrong**
   - Doc: "the production default is true".
   - Real default: `false` (`backend/src/config.rs:163-166`).
   - Impact: operators who trust the doc leave it unset; gateway
     refuses to start with the production fail-CLOSED guard.

5. **`docs/reference/http-api.md:71` — `/api/v1/execute` falsely marked deprecated**
   - Real: live route (`backend/src/proxy/http/gate/execute.rs:1-9`,
     `routes.rs:157`).
